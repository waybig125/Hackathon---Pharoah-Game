# Project Overview: The Alchemist’s Crypt

## Concept
A tactical "Agentic FPS" where a centralized Gemini 3 Flash Live Hive-Mind controls a tomb of mummies. The player uses elemental alchemy to fight back while the AI adapts to their strategy.

## Key Features
- **Centralized AI**: Gemini 3 Flash Live controls mummy tactics.
- **Alchemy System**: Three elements (Sulfur, Mercury, Salt) with tactical counters.
- **Mobile Optimized**: High performance, 30 FPS target, mobile-first controls.
- **PSX Aesthetic**: Retro-style visuals with thick sand fog for atmosphere and performance.

## AI Hive-Mind Roles
1. **The Strategist (Pharaoh)**: Plans maneuvers based on player behavior.
2. **The Arbiter (Referee)**: Monitors fairness and difficulty.
3. **The Empathy Agent (Reward)**: Injects mercy when the player is in danger.

## Tech Protocol
- **Communication**: JSON packets via WebSocket.
- **Input**: Legacy Input System.
- **Rendering**: URP with customized shaders and fog.
