# Walkthrough: Phase 1 Foundation

I have established the core mobile FPS foundation for **The Alchemist’s Crypt**.

## Key Achievements
- **Mobile FPS Controller**: Implemented a `Rigidbody`-based `PlayerController` that handles movement and camera rotation.
- **Unified Input**: Created `MobileInputManager` with desktop fallback (WASD/Mouse).
- **Mobile HUD**: Built a custom UI with:
    - **Joystick**: Controls movement.
    - **Touch Zone**: Controls looking (swipe to turn).
    - **Fire Button**: Triggers the Alchemical Focus.
- **Alchemy System**: 
    - Created `ObjectPooler` for efficient projectile management.
    - Implemented `AlchemicalFocus` with three modes (Sulfur, Mercury, Salt).
    - Created projectile prefabs with distinct materials (Orange, Teal, White).
- **Optimization**:
    - Target frame rate set to 30 FPS via `GameInitializer`.
    - Object pooling implemented for all projectiles.
